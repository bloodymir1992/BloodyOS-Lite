# BloodyOS Lite v0.6 — BloodyCat Edition 🐈‍⬛

A lightweight Linux distribution based on Debian 13, designed
to give older computers a second life.

## Features
- Debian 13 (Trixie), 64-bit
- Openbox desktop with XFCE panels
- Whisker application menu
- Thunar file manager
- Calamares graphical installer
- Linux Mint-style keyboard shortcuts
- Custom BloodyCat theme and wallpapers
- Integrated Bloody applications

## Installation
1. Download the ISO from GitHub Releases.
2. Create a bootable USB drive.
3. Boot into BloodyOS Lite.
4. Open "Install BloodyOS Lite" from the application menu.
5. Follow the Calamares installer instructions.
6. Select "Restart now" and click "Done" when finished.

## Compatibility
Designed for older computers while supporting modern x86_64 hardware.
Actual compatibility depends on the device and its drivers.
